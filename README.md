# Programa_de_Calculo_de_Porcentagem
O código calcula o valor final de um produto após a aplicação de um desconto. O usuário informa o preço e a porcentagem de desconto, e o programa realiza a conta automaticamente, mostrando o valor que deverá ser pago. No exemplo, um produto de R$ 100,00 com 20% de desconto passa a custar R$ 80,00.
