# Programa_de_calculo_de_Porcentagem
Este é um projeto simples desenvolvido em Python para calcular o preço final de um produto após a aplicação de um desconto.

O programa solicita ao usuário o preço do produto e a porcentagem de desconto desejada. Em seguida, realiza o cálculo automaticamente e apresenta o preço original, a porcentagem de desconto informada e o valor final do produto após o desconto.

O projeto foi desenvolvido com o objetivo de praticar conceitos básicos de programação em Python, como funções, parâmetros, retorno de valores, entrada de dados e cálculos matemáticos.
